# Oudu Software

**Native software and open-source integrations for Odoo.**

Oudu Software builds focused tools for working across Odoo instances, printing reports directly, and using local files and devices from a native desktop environment.

[![Oudu Desktop multi-account workspace](https://desktop.oudu.top/assets/shots/en-US/01-workspace.png)](https://desktop.oudu.top)

## Products

### [Oudu Desktop](https://desktop.oudu.top)

A free native Odoo desktop client for Windows, macOS and Linux. Connect to Odoo 08–19 and keep multiple servers and accounts open in isolated sessions.

- Work across multiple Odoo instances and accounts side by side.
- Print Odoo reports directly through system and network printers.
- Use local files, screenshots, cameras, microphones and scanners through explicit controls.
- Bring Odoo into native windows, notifications, downloads and shortcuts.

**[Download Oudu Desktop](https://desktop.oudu.top) · [Microsoft Store](https://apps.microsoft.com/detail/9NK0Z5PVPGJJ)**

### [Oudu Addons](https://github.com/oudusoft/oudu_addons)

Free LGPL-3 server modules for Odoo 13–19. They provide shared Oudu Software settings, instance identity, capability discovery and Oudu Desktop policies without modifying Odoo itself.

- `oudu_base` — shared settings, instance name/color/icon and the public capability manifest.
- `oudu_desktop` — desktop integration guidance, report printing policy, file upload policy and local source controls.

**[Choose your Odoo version](https://github.com/oudusoft/oudu_addons#choose-your-odoo-version)**

## 欧度软件

**面向 Odoo 的原生软件与开源集成。**

欧度软件专注于提升 Odoo 的桌面工作体验，让用户能够同时处理多个 Odoo 实例，直接打印报表，并安全使用本地文件与设备。

### [Oudu Desktop](https://desktop.oudu.top)

免费的 Windows、macOS 和 Linux 原生 Odoo 桌面客户端，可连接 Odoo 08–19，并以隔离会话同时运行多个服务器和账号。

- 多实例、多账号并行工作；
- 通过系统及网络打印机直接打印 Odoo 报表；
- 在明确授权下使用本地文件、截图、相机、麦克风和扫描仪；
- 获得原生窗口、通知、下载和快捷键体验。

**[免费下载 Oudu Desktop](https://desktop.oudu.top) · [Microsoft Store](https://apps.microsoft.com/detail/9NK0Z5PVPGJJ)**

### [Oudu Addons](https://github.com/oudusoft/oudu_addons)

适用于 Odoo 13–19 的免费 LGPL-3 服务端模块，在不修改 Odoo 源码的前提下，提供统一的欧度软件设置、实例标识、能力发现与 Oudu Desktop 策略。

- `oudu_base` — 统一设置、实例名称/颜色/图标与公开能力清单；
- `oudu_desktop` — 桌面集成引导、报表打印策略、文件上传策略与本地来源控制。

**[选择对应的 Odoo 版本](https://github.com/oudusoft/oudu_addons#choose-your-odoo-version)**
